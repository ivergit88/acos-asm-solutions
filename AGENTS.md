# Контекст для агента

Последнее правило защиты: поиск инструкций **Ctrl+F в Hex Editor без терминала**.
Читайте раздел 23 AGENT_HANDOFF.md: Find Bytes (hex), запрос слитно, без пробелов
и без0x. Старые терминальные сценарии — только для подготовки или с разрешения преподавателя.

Для помощи студенту во время подготовки/защиты сначала прочитайте
[AGENT_HANDOFF.md](AGENT_HANDOFF.md): там раскладка окон, быстрые ответы,
полная карта инструкций и правила самостоятельного поиска в бинарнике.
Полные сценарии: раздел 19 — min и for, раздел 20 — double.
Не пропускайте конец файла при ограничении длины чтения. В начале handoff
есть прямые ссылки на все три сценария; раздел 21 содержит словарь терминов.

Читайте README.md, docs/assignment.md и docs/explanation.md до изменений.
Это учебные NASM x86-64 программы для Linux, не Windows PE и не C-приложение.
Репозиторий полностью самодостаточен для агента с Linux-окружением.
Никакого доступа к исходному компьютеру пользователя не требуется.

## Структура и ограничения
- Корневые min.asm, for.asm, double.asm — действующие исходники с русскими комментариями.
- min: минимум ТРЁХ знаковых 32-битных значений, заданных -DA/-DB/-DC.
- for: чётные 0…N ВКЛЮЧИТЕЛЬНО, N по умолчанию 10; допустимо 0…65534.
- min/for возвращают ответ через exit, а не stdout. Учитывайте усечение до 8 бит.
- double: корректный ASCII-ввод 0…99 с LF, один read в 32-байтовый буфер;
  только read/write/exit, без libc, call/ret, push/pop и отдельных ASM-функций.
  Вывод строго Result: N плюс LF, без ведущих нулей, exit=0.
- Повтор короткого read/write и некорректный ввод за рамками исходного задания.
- Python-утилиты только проверяют или объясняют ASM, не заменяют его вычисления.

## Сборка и доказательства
Установить nasm, binutils, python3. Выполнить bash build.sh;
python3 -m unittest discover -v. Проверить прямые запуски ELF.
source_map.py сопоставляет NASM-листинг с байтами ОКОНЧАТЕЛЬНОГО linked ELF,
не с объектным .o (в нём ещё не исправлены межсекционные адреса).
ШПАРГАЛКА.md генерируется при сборке. reference/ обновляется через snapshot.sh.
После изменений кода сверять байты, номера строк, docs/double-report.md и samples.txt.
Не выдавать эталонные адреса за универсальные. .bss не имеет файлового содержимого.

## Учебная цель
Помочь понять и защитить самостоятельно, включая ModR/M, immediate,
little-endian, RIP-relative адреса, флаги и signed relative jump.
Не подменять объяснение самодельными командами автопоиска.
Не добавлять зависимости от VS Code, расширений, Windows-путей или GUI.
Не загружать учётные данные, личные данные или историю чата.
